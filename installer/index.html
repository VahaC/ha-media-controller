Media Controller panel installer

Install the touch-panel firmware on an ESP32-S3 board from this page, over a USB cable. No ESPHome, no YAML and no configuration file.

What this installs

One firmware image for the ESP32-S3-4848S040 — the 4-inch 480×480 board with an ST7701S display and a GT911 touchscreen. It is the only board this image is built for. Flashing it onto anything else will not damage the board, but nothing will be drawn on the screen.

The image is identical for every panel. It contains no Wi-Fi password, no Home Assistant address and no access token: those are added afterwards, on your own machine and on your own network.

Install

This browser cannot flash a device.

Installing needs Web Serial, which today means desktop Google Chrome, Microsoft Edge or Opera. Safari, Firefox and every browser on iOS and Android do not have it. Open this page in one of the three and the button below will appear.

This page is not on a secure connection.

Web Serial is only available over https:// (or on localhost). Open the published copy of this page instead of a local file or a plain http:// address.

  1. Connect the panel to the computer you are reading this on with a USB-C data cable. The cable has to carry data — a charge-only cable will power the panel and show up as nothing.
  2. Press Connect and pick the serial port.
  3. Choose Install Media Controller and confirm erasing the device. The first install takes about a minute.
  4. When it finishes, the same dialog offers Wi-Fi. Enter your network and password there.

Wi-Fi

The credentials you type into the Wi-Fi step travel down the USB cable to the panel and nowhere else. They are not sent to this site, to GitHub, or to any build server: this page never uploads anything, and the firmware it installs was built without them.

The panel stores them itself and reconnects on its own after a power cut.

If the network changes later

A panel that cannot reach its network raises its own access point, Media Controller Setup, after about a minute. Join it from a phone and a page opens where you can enter the new network. You can also plug the panel back into a computer and use the Connect button above, which offers the Wi-Fi step again without reinstalling anything.

Home Assistant

  1. Once the panel joins your network it shows a six-digit code on its screen and announces itself.
  2. Home Assistant offers it under Settings → Devices & services. Open it and type the six digits.
  3. Home Assistant then sends the panel its own address, an access token created for that panel alone, and the entity it should read. Nothing is typed on the panel itself.

The Media Controller integration has to be installed in Home Assistant first — through HACS — and a media player source configured. See the repository README.

If the panel is not offered

No serial port in the list

  • Try another USB-C cable. Charge-only cables are common.
  • On Windows, install the driver for the board's USB-to-serial chip (CH340 or CP210x) and unplug and replug the panel.
  • Close anything else holding the port — an ESPHome dashboard, a serial monitor, the Arduino IDE.

The port is there but the install fails to start

Put the board into its download mode by hand:

  1. Hold BOOT down.
  2. Press and release RESET.
  3. Release BOOT.
  4. Press Connect again.

Both buttons are on the back of the board. After a successful install the panel restarts on its own; if it does not, press RESET once.

Nothing on the screen after installing

Give it fifteen seconds — the display initialises after the rest of the firmware. If it stays dark, the board is probably not an ESP32-S3-4848S040.

Updating

Updates are installed the same way: connect the panel over USB and press Install again. There is deliberately no over-the-air update in this image — an update password compiled into a file anybody can download would protect nothing.

Installing over an existing panel keeps its Wi-Fi credentials and its Home Assistant pairing, so it comes back on its own. Choosing erase device clears both, and the panel then shows a new pairing code.
